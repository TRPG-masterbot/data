# 출력 — 배준호

마지막 수정: 2026-11-27 15:58 (한국시간)

1. ZIP을 풀고 **BAE 폴더 전체**를 GitHub `TRPG-masterbot/data`의 `main`에 업로드합니다.
2. `Output_Code.ipynb`에서 **출력 — 배준호 / O1~O6**만 통합 v1.3 출력 부분에 복사합니다.
3. 팀 공통·룰·시나리오·입력 준비 후 O1~O6을 실행합니다. 마지막 ngrok 셀은 그대로 유지합니다.

`Output_Code.ipynb`는 출력 복붙용이며 단독 실행본이 아닙니다.
모델·GPU 설정은 통합본을 사용합니다. 배포 파일과 셀의 버전이 일치해야 합니다.
이번 변경: 시작 가방은 식량·메디킷만 지급하고 직업 기본 장비는 유지합니다. 세라 수락 후 마을 정보를 얻을 촌장을 소개합니다. 할빅이 소개한 대장간·여관·우물가 중 방문할 곳은 플레이어가 고릅니다. 우물 관찰 뒤 현재 물품과 안전 하강 조건을 비교해 준비할 도구와 구입 장소를 안내합니다.
팀 원본과 공유 노트북·GitHub는 자동으로 수정하지 않았습니다.
