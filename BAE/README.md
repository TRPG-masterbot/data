# 출력 — 배준호

입력·룰·시나리오 RAG의 JSON을 받아 Qwen의 대사와 장면을 표시하는 출력 파트입니다.

1. 압축을 풀고 **BAE 폴더 전체**를 `TRPG-masterbot/data`의 `main`에 업로드합니다.
2. `Output_Code.ipynb`의 **출력 — 배준호 / O1~O6**만 최신 통합 v1.3의 출력 부분에 복사합니다.
3. 공통·RAG·입력 준비 후 출력 셀을 순서대로 실행합니다.

`Output_Code.ipynb`는 복붙용이며 단독 실행본이 아닙니다. 모델 설정은 통합본의 공통 값을 사용합니다.
핵심 코드와 주요 프롬프트는 6개 셀에, 반복 처리·검사·UI·이미지는 `src/`에 있습니다.
O1은 필요한 파일만 확인해 받고 다음에는 캐시를 사용합니다. 현재 BAE 게임 자료 사본은 이번 출력 수정에서 변경하지 않았습니다. 김재혁 원본과의 차이는 SOURCES.md에 명시합니다.
이미지는 기존의 작은 WebP를 유지합니다. 기존 `BAE/src/assets`의 같은 이름 PNG 7개는 삭제하고 새 WebP를 사용합니다.
마지막 수정일은 출력 제목 아래에, 실제 GPU·모델·양자화는 O6에 표시합니다.
