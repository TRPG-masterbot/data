# 출력 — 배준호

팀 입력·룰·시나리오 RAG의 자료를 받아 Qwen의 대사와 장면을 표시하는 출력 파트입니다.

1. ZIP을 풀고 **BAE 폴더 전체**를 `TRPG-masterbot/data`의 `main`에 업로드합니다.
2. `Output_Code.ipynb`의 **출력 — 배준호 / O1~O6**을 공유 통합 v1.3의 출력 부분에 복사합니다.
3. 팀 공통·룰·시나리오·입력 준비 후 O1~O6을 실행합니다. 기존 마지막 ngrok 셀은 그대로 둡니다.

`Output_Code.ipynb`는 출력 부분 복붙용이며 단독 실행본이 아닙니다.
모델·GPU·양자화는 통합본의 공통 설정을 사용합니다.
게임 엔진이 확정한 전투 결과에 명중·피해·치유 표시를 연결하고, 몬스터 그림은 작은 WebP로 표시합니다.
핵심 코드와 프롬프트는 O1~O6에, 파일 준비·검사·화면·이미지는 `src/`에 있습니다.

배포 목록과 O1의 SHA-256이 같은 버전인지 확인합니다.
GitHub 업로드는 이 파일 생성에 포함되지 않습니다. BAE 업로드 후 출력 셀을 교체합니다.
파일 출처와 원본 보존 범위는 `SOURCES.md`에 정리했습니다.
