# 실행 코드의 출처

- 룰·시나리오 검색과 입력 JSON은 최신 통합본의 팀 함수를 호출합니다.
- `src/game`은 김재혁 `Kim/TheDrownedBell/game` 기반의 BAE 수정 사본입니다.
  최신 김 원본을 직접 import하는 구조가 아니며, 완전한 독자 엔진도 아닙니다.
- 카드 166개 중 6개와 일부 장면 정의가 김 원본과 다릅니다. 이번 출력 개선에서는
  이 사본을 추가 수정하거나 김 원본으로 임의 교체하지 않았습니다.
- UI·AI 대화 연결·진행 안내·진단은 BAE 출력 모듈이 담당합니다.
- 이번 배포의 정확한 파일 버전은 `src/runtime-manifest.json`에 있습니다.
